Auto Slip Claim - Patch 50% + บันทึกชื่อที่ต้องตรวจ (v4.3 / userscript 5.4)

ไฟล์:
1) Auto_Slip_Claim.user.js   (Tampermonkey)  นำเข้า/แทนที่สคริปต์เดิม
2) server.js                 ใช้แทน server.js เดิม (สำรองไฟล์เดิมไว้ก่อน)
3) start.bat / package.json / package-lock.json   ใช้แทนของเดิมได้เลย (ปรับแค่เวอร์ชัน + เช็ค Library ให้แน่นขึ้น)

------------------------------------------------------------
สิ่งที่เพิ่มในเวอร์ชันนี้: unmatched_names.txt
------------------------------------------------------------
ไฟล์ unmatched_names.txt จะมีบรรทัดรูปแบบ   ชื่อไทย = ชื่ออังกฤษจากสลิป   เมื่อเข้าเงื่อนไขอย่างใดอย่างหนึ่ง (เฉพาะการเทียบข้ามภาษาไทย<->อังกฤษ):
  A) แปลไม่ได้ / เทียบแล้วไม่ผ่านเกณฑ์ 50%   (พฤติกรรมเดิม)
  B) เทียบ "ผ่าน" แต่ความเหมือนต่ำกว่า 70%   (เพิ่มใหม่ -- อนุมัติได้ตามปกติ แต่เก็บไว้ให้ตรวจสะกด)

ไม่บันทึกในกรณีเหล่านี้:
  - ชื่อคู่เดิมที่มีอยู่ในไฟล์แล้ว (ซ้ำ)  หรือมีใน name_overrides.txt อยู่แล้ว
  - ความเหมือนตั้งแต่ 70% ขึ้นไป (รวมถึงสะกดตรง dictionary 100%)
  - dictionary ยืนยันแล้วว่าเป็นคนละชื่อ (เช่น สมชาย vs SOMMAI)
  - ชื่อภาษาเดียวกัน (ไทย-ไทย / อังกฤษ-อังกฤษ)

วิธีใช้: เปิด unmatched_names.txt ตรวจแต่ละบรรทัด ถ้าเป็นคนเดียวกันจริง ให้ก๊อปบรรทัดไปวางใน name_overrides.txt
(บันทึกแล้วใช้ได้ทันที ไม่ต้องรีสตาร์ท) -- ในไฟล์มีแต่บรรทัดล้วน ๆ ไม่มีหมายเหตุ เพื่อให้ก๊อปได้ตรง ๆ
เหตุผลของแต่ละบรรทัด (ไม่ผ่าน / ผ่านแต่กี่ %) ดูได้ที่ console ของ server และ console ของเบราว์เซอร์ตอนบันทึก

ปรับเกณฑ์ 70%: แก้ค่า NAME_REVIEW_PERCENT ทั้งใน server.js และ Auto_Slip_Claim.user.js (ให้ตรงกัน)

------------------------------------------------------------
แก้เรื่องความเสถียร/ไฟล์ไม่สมบูรณ์
------------------------------------------------------------
- google_name_cache.json เคยว่างเปล่า 0 ไบต์ (เกิดตอนปิดโปรแกรมระหว่างเขียนไฟล์)
    -> เขียนไฟล์แบบ atomic (เขียนไฟล์ชั่วคราวแล้วค่อยเปลี่ยนชื่อทับ)
    -> เซฟแคชที่ค้างอยู่ก่อนปิดโปรแกรม (Ctrl+C / ปิดหน้าต่าง)
    -> ไฟล์ว่างเปิดได้ปกติ ไม่ error / ไฟล์เสียจะสำรองเป็น .bak แล้วเริ่มใหม่
- server ไม่ล้มทั้งตัวจาก error ที่ไม่ได้ดักไว้ (บันทึกลง console แล้วทำงานต่อ)
- เปิด server ซ้ำ (พอร์ต 5001 ถูกใช้อยู่) -> แสดงข้อความชัดเจนแล้วปิดตัวเอง แทนที่จะค้าง
- request ที่ผิดรูปแบบตอบเป็น JSON เสมอ
- ตอนเปิด server แสดงสรุปสถานะ (จำนวน overrides / แคช / Google / คำเตือนใน name_overrides.txt) ไม่ให้ถูก console.clear() ลบทิ้ง
- Userscript: ถ้า server ไม่ตอบตอนส่งรายงาน รอบถัดไปจะลองส่งใหม่ (เดิมถูกนับว่าส่งแล้วและไม่ลองอีกจนกว่าจะรีเฟรชหน้า)
- start.bat: เช็ค node_modules\express (เดิมเช็คแค่มีโฟลเดอร์) + แจ้งเตือนถ้าติดตั้ง Library ไม่สำเร็จ
- เวอร์ชันใน package.json / package-lock.json / start.bat / server.js ตรงกันเป็น 4.3.0

------------------------------------------------------------

------------------------------------------------------------
